In order to get vectors working, we need a few changes.
Vectors of objects look like this:
MyOb[(...), (....), ...]
Thus these child nodes do not have attached explicit 'data' tags as graftFrag() currently expects.
Here are the options:
- rework graftFrag to return a vector of syntacticalBranch; assign this to the children field of the overarching branch elsewhere.
  con: we need a new function to get an individual object. messy.
- break child-getting code out of graftFrag into new function; graftFrag calls it and uses the results in different ways for vectors and normal objects.
  basically the same as the first option, but better.
  con: more copying? idk
